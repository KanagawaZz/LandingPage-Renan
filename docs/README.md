## Executar localmente

```bash
npm install
npm run dev
```

## Gerar a versão de produção (Vercel / Hospedagem Estática)

```bash
npm run build
npm run preview
```

Os arquivos de produção otimizados são gerados na pasta `dist/`.
Deploy direto na Vercel: basta conectar o repositório Git ou executar `vercel`.
