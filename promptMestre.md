Sua missão é criar uma LANDING PAGE COMPLETA, FUNCIONAL, VISUALMENTE PREMIUM E PRONTA PARA PUBLICAÇÃO para um advogado criminalista.

A página deve transmitir, nos primeiros 3 segundos:

• confiança
• autoridade
• discrição
• acolhimento
• profissionalismo
• segurança
• clareza

O visitante não deve sentir que está diante de um "site jurídico genérico". A experiência deve parecer a de um escritório moderno, sofisticado e confiável.

IMPORTANTE:
O objetivo NÃO é vender agressivamente.
O objetivo é fazer o visitante pensar:

"Posso conversar com esse advogado sobre o meu caso."

E então clicar no WhatsApp.

==================================================
12. ANIMAÇÕES
==================================================

As animações devem transmitir sofisticação, não chamar atenção para si mesmas.

Utilizar:

• fade-in;
• translateY extremamente sutil;
• stagger de 80–120ms;
• hover discreto;
• transições de 400–700ms;
• easing suave;
• barra de progresso de scroll extremamente fina;
• parallax muito sutil no desktop.

Elementos devem aparecer conforme entram no viewport utilizando Intersection Observer.

O botão de WhatsApp pode possuir um pulso muito discreto.

NÃO utilizar:

• animações exageradas;
• zoom agressivo;
• textos piscando;
• elementos saltando;
• carrosséis automáticos;
• contadores falsos;
• efeitos de urgência.

Implementar:

@media (prefers-reduced-motion: reduce)

para reduzir/desativar animações.
